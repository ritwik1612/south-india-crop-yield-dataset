Inside the future computation

  1. Validate location, season and area
  2. Obtain weather and create 21 predictors
  3. Apply fitted imputer, scaler and encoding
  4. Encode using the Denoising Autoencoder
  5. Run a trained MLP or GBDT regressor
  6. Return rice yield in tonnes/hectare
These stages are illustrated here; only input validation and the fixed demo calculation run.

PREPROCESSING · FITTED

Denoising Autoencoder (DAE)

21 → 64 → 32 → 8 → 32 → 64 → 21. Learns to reconstruct clean predictors from noisy standardized inputs. Exports 8 latent features.

pre-processing/denoising_autoencoder.py
8latent features
CONVENTIONAL PREPROCESSING · FITTED

SimpleImputer + StandardScaler + OneHotEncoder

Training-set median filling, z-score scaling and state/season indicators. These transforms precede the DAE and also supply a conventional baseline representation.

28baseline predictors
YIELD COMPUTATION · NOT TRAINED

HistGradientBoostingRegressor (GBDT)

Tabular baseline and controlled comparison. Learns nonlinear decision rules from conventional or DAE predictors and yield labels.

01yield output
TABULAR DL COMPUTATION · NOT TRAINED

Multilayer Perceptron (MLP) regressor

Dense layers 64 and 32 connect latent/context inputs to the yield target. This is the initial tabular DL model, not the original paper's sequence model.

64/32hidden units
PAPER-BASED SEQUENCE MODELS · FUTURE

Long Short-Term Memory (LSTM) + 1D CNN

LSTM learns dependencies across weather steps. One-dimensional convolution learns local temporal patterns. Both require weather sequence preparation and supervised training.

10weather channels

No trained yield model, disease detector, nutrient classifier or calibrated uncertainty model is connected to this prototype.
