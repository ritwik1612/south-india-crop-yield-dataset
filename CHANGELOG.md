# Changelog

## v1 — 2026-09-14

- Added 66,172 valid crop-statistics records for Andhra Pradesh, Karnataka,
  Tamil Nadu and Telangana.
- Added the 3,554-row district/season/year rice-yield target table, crop-area
  table, and state-season area-fraction table.
- Added a transparent GADM district-centroid crosswalk: 70 matched districts
  and a separate 52-district review file.
- Added 588,000 real daily NASA POWER weather observations (2001–2023) and a
  57,960-row ten-day aggregation.
- Documented the Netherlands-schema mapping and explicitly deferred unavailable
  remote-sensing, soil/terrain, and WOFOST tables.
